Powered by Gnani AI

Every spoken word in Remo — both listening and speaking — runs on Gnani’s speech models.

STT · v2.5

Prisma

Realtime WebSocket streaming (16 kHz / 1024-byte PCM + REST fallback) for Hinglish and Marathi, boosted by your own note vocabulary.

TTS · v2.5

Timbre

Speaks every confirmation, recall answer, morning plan, quiz prompt, and alarm using Nalini (Hinglish) and Zahira (Marathi) with local disk caching.

Your memory stays yours

Plain facts about where your voice, notes, and watched links live.

Stays on your machine

Notes, work entries, reminders, boost words, fix rules, and keys live locally in ~/.remo. No Remo cloud server exists.

Sent to Gnani

Audio during mic capture goes to Prisma for transcription, and reply text goes to Timbre for synthesis. Nothing else leaves.

Watched sources

GitHub repos or issues you explicitly watch are polled via plain public HTTP requests. Your personal notes are never sent out.

Honest current limits

  • Understanding is extractive today (no LLM in the loop yet) — fast and deterministic on your words; Evon reasoning is next.
  • The repository noise benchmark uses Timbre-synthesized Hinglish overlays until field recordings land.
  • Quiz grading and reminder read-backs stay Hinglish-first pending native Marathi review.
  • Single-user local studio: no accounts or cloud sync by design.
Local Quick Start

Run Remo in two minutes

Paste a key from app.gnani.ai/voice into .env and launch the studio locally.

python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn server:app --host 127.0.0.1 --port 8000
